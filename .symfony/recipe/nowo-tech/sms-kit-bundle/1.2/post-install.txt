Nowo SMS Kit Bundle installed.

1. Set up nowo-tech/instance-settings-bundle first (table, encryption key, admin UI routes): the "sms" section lives there.
2. Open /admin/settings/sections/sms, choose a provider (log for development), its credentials and a test recipient,
   then press "Send a test SMS" (route import added in config/routes/nowo_sms_kit.yaml).
3. DB-only mode: no environment variable is needed. Hosts migrating from SMS_PROVIDER / TWILIO_* / SMS_BRIDGE_*
   fallbacks run php bin/console nowo:instance-settings:seed-from-fallbacks --section=sms before removing them.
4. Send from code with Nowo\SmsKitBundle\Sender\SmsSenderInterface, or test with:
   php bin/console nowo:sms:send +15550100123 "Hello"

Docs: https://github.com/nowo-tech/SmsKitBundle/tree/main/docs
